# 0004. The coach is a guarded prompt with read-only access

## Context

An AI assistant is useful for weekly reviews, but it can invent rules, quote outdated numbers, drift outside training topics or edit notes it should not touch.

## Decision

The coach is a prompt (`agents/coach.md`) over read-only sources, with fixed limits:

- it reads the methodology index first and opens only the note the question needs;
- it cites the note behind every rule and the report behind every number;
- it does not diagnose and gives no medical or nutritional advice; out-of-scope questions are referred to a professional;
- it may propose a rule change, but the current rule holds until the person confirms;
- it writes only to an inbox folder, one file per delivery, and never to the database, the repository or other notes.

The ETL stays descriptive: `report.py` describes, the coach interprets, the person decides.

## Alternatives considered

- **Rules hard-coded in the prompt.** They go stale; the prompt points to the notes instead.
- **Agent with write access to the notes.** Faster edits, but a wrong edit would be silent.
- **Recommendations generated by the ETL.** Would mix methodology into code; methodological fields are marked `TODO(metodologia)` instead.

## Consequences

- Every claim in a review is traceable to a note or a report section.
- Rule changes leave a dated record.
- The coach is only as good as the report, which is why `verify.py` exists.
